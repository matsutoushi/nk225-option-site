## 2. この数字から言えること

### AdSenseは、今の規模では主役になれない

2,395セッション×2〜3ページ = 月5,000〜7,000PV。
金融ジャンルのRPMを¥400〜800とすると **月¥2,000〜5,000** が上限。
審査がまだ通っていないことを差し引くと、当面は**ゼロと見て設計する**のが正しい。

### アフィリエイトは、1件で数ヶ月分をひっくり返す

SBI証券の口座開設が1件成約すれば、AdSenseの数ヶ月分になる。
つまり**「月間何件」ではなく「最初の1件をどこから出すか」**を設計する段階。

### 成約母集団は検索流入だけ

- **X(47.5%)は滞在1分08秒。**タイムラインで数字だけ見て離脱している。
  拡散とリピーターには効くが、口座開設まで進む層ではない
- **検索(15.7%)は滞在2分06秒・エンゲージ65.2%。**読んでいる。
  「日経225オプション 始め方」に近い意図で来た人だけが成約する
- Directの58秒は、自分・ブックマーク・ボットが混ざった数字。過大評価しない

**流入の47.5%を占めるチャネルからは、ほぼ売上が立たない。**
これが今の構造上の問題で、記事を増やすべき理由もここにある。

### AI Assistant 10.2% は無視できない

開設3か月でChatGPT/Claude/Perplexity等からの流入が1割。まだ収益にはならないが、
**「数字を断言している一次情報のページ」はLLMに引用されやすい**という仮説を裏づける。
当サイトは自前で計算した実測値を持っているので、この特性は強みになる。

## 3. 方針

### 優先度1: 検索の表示回数を増やす(唯一の複利)

平均順位9.1は「1ページ目の下」で、CTR 2.1%は順位相応。
**順位を上げる施策より、表示回数3,500を増やす施策のほうが伸びしろが大きい。**

上位クエリは「建玉分布」34表示、「ガンマエクスポージャー」30、「市場建玉分布」23、
「先物 手口 マトリックス」18。**いずれも既に記事があるテーマ**で、
まだ取れていないテーマの記事が足りていないということ。

- 検索実績のあるクエリの周辺に記事を足す(SQ・IV・限月・証拠金あたり)
- 1記事あたり2,500字以上、実測値を必ず1つ以上入れる
- 記事同士を相互リンクして滞在時間を稼ぐ

### 優先度2: 成約導線を、読まれている記事の側に置く

2026-07-27のGA4で、`guide-start.html` は滞在11秒で直帰していた一方、
解説記事は滞在1分超で読まれていた。そこで**記事末尾にCTAブロックを置く**方式にしてある
(`PR_NOTE` + `CTA_BROKER` / pages.py)。この判断は実測に基づくもので、変えない。

いま適用されているのは6記事(建玉・PCR・GEX・COT・手口・SQ)。
**新しく追加した guide-brokers / guide-jpx-data には付いていない**ので、ここを揃える。

- 出口の比較ページは `guide-start.html` のまま。CTAから1本送る
- トップ(データ)には置かない。ツールとしての信頼を優先する
- PR表記は該当ページ冒頭に必ず入れる(SoftBank Airの掲載条件と同じで、消すと契約違反)

### 優先度3: AdSenseは通れば加算、落ちても計画を変えない

審査結果待ち。通ったら記事ページにのみ表示し、トップのファーストビューには置かない。
**AdSenseありきの計画にしない。**

### 保留: 有料化は「月3,000クリック」を超えてから

いま有料にできる在庫は**取引参加者別建玉の52週分の履歴**(49社・週次)。
JPXは過去ファイルをまとめて出していないので、蓄積そのものに値段がつく可能性がある。
ただし**無料の読者が十分に育つ前に有料化すると、両方失う。**
検索クリックが月300件を超えるまでは無料で配り切る。

## 4. 判断基準

| 時期 | 見る数字 | 分岐 |
|---|---|---|
| 2026年12月 | 検索クリック(月) | 100件超 → アフィリエイト強化 / 50件未満 → テーマを見直す |
| 2026年12月 | AI Assistant構成比 | 15%超 → 構造化データに投資 |
| 2027年3月 | 検索クリック(月) | 300件超 → 有料データの検討を開始 |

いま追うべき数字は売上ではなく**検索クリック数**。ここが動かないうちは、
どの収益手段を足しても結果は変わらない。
