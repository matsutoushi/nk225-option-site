# research/

サイトの生成には使わないが、記事やX投稿を書くときの下調べに使う一次資料を置く。
ここのファイルは `site/` に出力されない。

## 収集対象

`fetch_warsh.py` が federalreserve.gov から集める(米国政府の著作物なのでパブリックドメイン)。

| ディレクトリ | 中身 | role |
|---|---|---|
| `warsh/` | ウォーシュ本人の講演・議会証言 | `governor` / `chair` |
| `fomc/` | 就任後のFOMC声明・議事要旨 | `fomc` |

各ファイルの先頭4行に日付・役職・出典URLが入っている。`index.json` に一覧がある。

## 自動更新

GitHub Actionsの日次ジョブ(`daily-update.yml`)の「Update Fed research corpus」ステップが
毎営業日回る。新しい文書が出れば `data` と一緒にコミットされる。

FRBのRSSは直近十数件しか載らないため、**毎日回すことが取りこぼし防止になっている**。
止まると新しい講演が取れなくなるので、失敗しても気づけるようログは残す
(ビルド自体は止めない `continue-on-error: true`)。

手動実行:

```bash
python research/fetch_warsh.py          # 差分だけ取得
python research/fetch_warsh.py --force  # 保存済みも取り直す
```

## 取得経路が2つある理由

FRBのサイト構造がそうなっている。

- **2011年以前**: 年次インデックス(`/newsevents/speech/2010speech.htm`)に一覧がある
- **最近の年**: 年次インデックスが存在しない(2026年分は404)。RSSしか入口が無い

議事要旨だけは扱いが特殊で、RSSのリンク先は800字程度の告知ページにすぎない。
本文(4万字前後)は `/monetarypolicy/fomcminutes{YYYYMMDD}.htm` 側にあるので、
告知ページからリンクを辿って取得している。

## 使うときの注意

**ウォーシュの議長就任は2026年5月22日**(任期2030年5月21日まで)。
出典: <https://www.federalreserve.gov/aboutthefed/bios/board/warsh.htm>

就任後の本人の公開文書はまだ少なく、大半は理事時代(2006-2010)、
つまり金融危機とその直後のもの。**在野・一理事としての発言と議長としての行動が
食い違いやすいのは金融政策の領域そのものなので、理事時代の発言を根拠に
議長としての考えを断定しないこと。**

`fomc/` は委員会の合意文書であって本人の見解ではない。ただし声明には
反対票を投じた委員の氏名が明記される(例: 2026年7月29日は9対3で、
Hammack・Kashkari・Logan の3名が25bp利上げを主張)。

## 使い方

Claude Code のサブエージェント `warsh` がこのコーパスを読む。
定義は `~/.claude/agents/warsh.md`(プロジェクト側にも同じものを置いてある)。

```
warsh に「今回の議事要旨の9対3をどう読むか」と聞いて
```

エージェントは「実際に言ったこと(引用+出典)」と「そこからの推測」を必ず分けて返す。
本人になりすまして一人称で語ることはしない。
