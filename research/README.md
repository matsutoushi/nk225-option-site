## warsh/

ケビン・ウォーシュFRB議長の発言コーパス。`fetch_warsh.py` が
federalreserve.gov から収集する(米国政府の著作物なのでパブリックドメイン)。

```bash
python research/fetch_warsh.py          # 差分だけ取得
python research/fetch_warsh.py --force  # 全部取り直す
```

**2026-08時点で、議長就任後の公開文書は2026年7月14日の議会証言1本しかない。**
残る18本はすべて理事時代(2006-2010)、つまり金融危機とその直後のもの。

在野・一理事としての発言と議長としての行動が食い違いやすいのは金融政策の領域そのものなので、
**理事時代の発言を根拠に議長としての考えを断定しないこと。** 各ファイルの先頭に
`role: governor` / `role: chair` を入れてあるのはこのため。

`index.json` に日付・タイトル・役職・出典URLの一覧がある。

### 使い方

Claude Code のサブエージェント `warsh` がこのコーパスを読む。
定義は `~/.claude/agents/warsh.md`。

```
warsh に「今回の議事要旨の9対3をどう読むか」と聞いて
```

エージェントは「実際に言ったこと(引用+出典)」と「そこからの推測」を必ず分けて返す。
本人になりすまして一人称で語ることはしない。
